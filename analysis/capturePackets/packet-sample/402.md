# Opcode 402 - Player Information Response

Documents the structure of the Opcode 402 network packet, used in TotalBattle to request and receive player information for objects on the game map.

---

## Overview

- **Opcode:** `402`
- **Purpose:** Request/retrieve player details for specific map objects (monsters, citadels, players etc.)
- **Transport:** MessagePack (binary encoded), wrapped in base64 for capturestore.
- **Header:** First 8 bytes are two u32-LE length fields (total packet length, payload length).


## Request Structure

The request consists of two MessagePack fragments:

### Fragment 1 - Header
```json
[402, 958, [[1215476012623], {type: "Buffer", data: [...]}], ""]
```

### Fragment 2 - Object ID List
```json
[
  [[1215475896275]],   // map object ID to query (array of 1)
  [[1215475823320]],   // another object ID
  [[1215475787029]]    // another object ID
]
```

Each object ID is a large integer (representing an int64 value) wrapped in a single-element array.


## Response Structure

The response also has two fragments:

### Fragment 1 - Header
```json
[402, 958]            // opcode, sequence number
```

### Fragment 2 - Player Objects Array
A top-level array containing a single array of player objects. Each player object is a `23`-element array.

```json
[
  [
    [/* player 1 (23 elements) */],
    [/* player 2 (23 elements) */],
    [/* player N (23 elements) */]
  ]
]
```

## Player Object (`23 fields`)

Every response entry is an array of `23 elements`, in the following order:

| Index | Type | Description | Example Values |
|-------|------|-------------|----------------|
| 0 | `Array` | `**Player ID**`: single-element array containing the map object ID that was queried. | `[[1215475787029]]` |
| 1 | `String` | `**Progress ID**`: unique player identifier in format `tb:{N}`. | "tb:69488593"` |
| 2 | `String` | `**Player Name**`: the player display name. | "Majkulec"`, "Lanien"`, "Fieglod"` |
| 3 | `String` | `**Country Code**`: 2-letter ISO code of the player registered country. | "NO"` (Norway), "US"` (USA), "ES"` (Spain) |
| 4 | `Number` | `**Hero Type**`: numeric ID of the hero. Example: 2=Alrick, 3=Thaddeus. Unknown values in sample: 1,5,6. | `1`, `2`, `5`, `6` |
| 5 | `Number` | `**Unknown**`: always `9` in samples. Possibly a hero sub-type or skin ID. | `9` |
| 6 | `Number` | `**Unknown**`: varies (1, 1, 196, 197, 10000030). May be a skin or hero equipment ID. | `1`, `196`, `197`, `10000030` |
| 7 | `Number` | `**Hero Level**`: the level of the player primary hero. | `14`, `33`, `36`, `41`, `57`, `40`, `47` |
| 8 | `Number` | `**City Level**`: the level of the player city. | `15`, `17`, `19`, `20`, `22`, `24`, `25` |
| 9 | `Number` | `**Unknown**`: small integer, possibly a rank or hero class. | `2`, `4`, `5`, `8`, `9`, `10` |
| 10 | `Number` | `**Might**`: total player power score. | `394512`, `180416`, `214290`, `7670046` |
| 11 | `Array` | `**Clan ID**`: single-element array containing clan ID or `[0]` if no clan. | `[1215475744834]`, `[0]` |
| 12 | `Number` | `**Unknown**`: possibly a clan-level or internal ID. Matches across players in the same clan. | `2035208`, `0`, `1316869` |
| 13 | `String` | `**Clan Name**`: abbreviation of the player clan, or empty string if no clan. | "ptl"`, "OGR"`, `` |
| 14 | `Number` | `**Unknown**`: always `0` in samples. | `0` |
| 15 | `Array` | `**Coordinates**`: `[kingdom, x, y]` of the player city on the game map. | `[283, 740, 378]` |
| 16 | `Array` | `**Object ID**`: single-element array, possibly a timestamp or session ID. varies per player. | `[1215518144422]` |
| 17 | `Number` | `**Gold**`: player gold amount in the treasury. | `4`, `266`, `703`, `16`, `3453`, `68`, `9034`, `4582` |
| 18 | `Number` | `**Unknown**`: possibly gold ingots or secondary resource. | `1547`, `1020`, `2021`, `41446`, `85789`, `38576`, `430127`, `30806` |
| 19 | `Array` | `**Unknown**`: empty array `[]` in samples. Possibly alliances or troops. | `[]` |
| 20 | `Array` | `**Flags / Trophies**`: array of `[id, count]` pairs. Universally always contains `[[300, 1]]` in samples. Some players have additional items. | `[[300, 1]]` |
| 21 | `String` | `**Timezone**`: player timezone in format `(UTC{+/-}Nnn)` where Nnn is the offset in *100ths of an hour*. | "(UTC-100)"`, "(UTC+500)"`, "(UTC-300)"`, "(UTC+600)"` |
| 22 | `Array` | `**Unknown**`: always `[0]` in samples. | `[0]` |

1. **Object ID vs. Player ID:**
   - `[0]` is the *map object ID*, which matches the ID queried in the request.
   - `[1]` (`progressId`) is the *persistent player ID* (format `tb:{N}`).
   - The object ID changes on relogin/respawn; the progress ID is stable.

2. **Clan fingerprinting:**
   - `[11]` is the clan ID in an array. `[0]` means no clan.
   - `[12]` is a numeric value that *matches across all players in the same clan*.
   - `[13]` is the clan abbreviation (string).

3. **Hero Types observed:**
   - `1` is the most common (likely the default or starting hero).
   - `2` = Alrick
   - `3` = Thaddeus
   - `5`, `6` seen in sample (may be Alvar, Sventhilda, or other rare heroes).

4. **Unknown Fields:**
   - `[5]` (always `9`): likely a hero sub-type, rare ID, or class ID.
   - `[6]` (varies: `1`, `196`, `197`, `10000030`): likely a skin ID or hero equipment preset.
   - `[9]` (small integers `2`..`10`): possibly a rank, league, or hero class.
   - `[12]` (matches per clan): likely a clan level or clan ID in another format.
   - `[14]` (always `0`): reserved or unused field.
   - `[16]` (varies per player): likely a timestamp or session ID.
   - `[18]` (varies): possibly gold ingots or a secondary resource.
   - `[19]` (always `[]`): empty array, possibly alliances or troops.
   - `[22]` (always `[0]`): unknown single-element array.

5. **Flags / Trophies ([20]):**
   - Universally contains at least `[[300, 1]]` (where `300` is likely a flag/trophy type ID).
   - Some players have multiple items: `[[234, 1], [300, 1], [329, 1], [366, 1]]`
   - This array may represent collected flags, trophies, or bonus items.

6. **Timezone Format:**
   - Format: `(UTC{+/-}Nnn)` where `Nnn` is the offset in *100ths of an hour*.
   - Examples: "(UTC-100)" = UTC-10, "(UTC+500)" = UTC+5, "(UTC-300)" = UTC-3, "(UTC+600)" = UTC+6

7. **Coordinates:**
   - Field `[15]` is a 3-element array: `[kingdom, x, y]`
   - All players in the sample are in `kingdom 283`.

8. **Two Versions of Player Objects:**
   - **23-field version** (this document): used in Opcode 402 responses. Contains player info, hero level, city level, might, gold, clan, timezone.
   - **42-field version** (in `messagePack.js` opcode 312): battlefield/map object. Includes source/target coords, shield status, and more.
